# 功能与规则基线 (阶段二确认)

## 一、配置与连接功能
- **FUNC-01** 创建 Sirchmunk 服务连接
- **FUNC-02** 修改 Sirchmunk 服务连接
- **FUNC-03** 检查服务连接
- **FUNC-04** 绑定 DSH MCP 连接
- **FUNC-05** 验证 MCP 能力
- **FUNC-06** 停用或移除服务连接

## 二、检索委托功能
- **FUNC-07** 发起 Sirchmunk 检索委托
- **FUNC-08** 消费并展示检索结果
- **FUNC-09** 重试失败的检索委托

## 三、管理页面功能
- **FUNC-10** 打开 Sirchmunk 管理中心
- **FUNC-11** 查看知识图谱
- **FUNC-12** 查看和管理知识资产
- **FUNC-13** 查看历史记录
- **FUNC-14** 查看运行监控
- **FUNC-15** 查看和修改 Sirchmunk 设置

## 四、安全与控制规则
- **R-01**: 服务连接地址只允许安全的 URL。
- **R-02**: 不保存明文 Token，凭据/敏感信息隔离并脱敏。
- **R-03**: MCP 发现 `sirchmunk_search` 及兼容 Schema，否则标识为不兼容。
- **R-04**: 删除连接不级联删除 DSH 历史或 Sirchmunk 数据。
- **R-05**: DSH Agent 按问题复杂度选择检索模式，并尊重用户明确指定的 FAST/DEEP/FILENAME_ONLY；不拆分 Sirchmunk 内部步骤，控制 DSH Token 与上下文。
- **R-06**: MCP 失败不自动降级使用 DSH 昂贵模型重检索。
- **R-07**: 插件管理页只展示后端提供能力，无后端功能不虚构，禁普通 iframe。
- **R-08**: 插件不可改写后端，破坏性操作必须二次确认，只读查询可有限重试，写失败不重试/不补偿。
