# 阶段七：UI 原型基线（第一、二组）

状态：用户已确认第一、二组问题均按 AI 建议。

## 总体结构

- DSH 设置中提供 Sirchmunk 单表入口概览（UI-01）。
- 独立插件管理中心承载图谱、聚类、历史、监控与设置，通过 DSH 插件路由呈现，不使用 iframe。

## 连接与 MCP

- UI-02 服务连接：LIST_MAINTENANCE 布局，表单包含“保存”与“保存并检查”，凭据安全脱敏。
- UI-03 MCP 绑定：LIST_MAINTENANCE 布局，只能选择 DSH 已有 MCP 连接，解除绑定不删除底层 MCP 连接。
- 移除连接：删除插件配置，不级联删除 DSH 历史对话和 Sirchmunk 后端数据。

## 图谱与聚类

- UI-04 知识图谱：中央画布 + 右侧详情面板；不保存前端拖拽的自定义布局。
- UI-05 知识聚类：QUERY_LIST 布局，提供详细过滤和分页；缺失字段显示“未提供”。
- 聚类删除：仅管理员可执行，弹窗要求输入聚类名称二次确认。
- 图谱导出：新增 FUNC-16 导出当前过滤视图（使用者允许），新增 FUNC-17 导出全部可见图谱（仅管理员允许）。

## 交互原则

- 界面操作与数据渲染均不自动注入 DSH 对话上下文，也不暗中调用高价模型。
- 不提供 Chat 页面。
