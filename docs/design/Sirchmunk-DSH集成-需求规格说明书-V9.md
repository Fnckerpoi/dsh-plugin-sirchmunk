# Sirchmunk-DSH 知识库检索与图谱协同管理系统 需求规格说明书 V9.0

## 第一部分 总体描述
本系统旨在打通 Sirchmunk 本地高保真无索引检索内核与 DSH 智能体工作台，彻底替代 Sirchmunk 独立 Web GUI。在 DSH 中通过 MCP 协议委托检索，同时通过 DSH 插件提供非 Chat 页面的管理入口（如图谱、聚类、监控）。

**业务范围：**
- 范围内：检索任务调度、模式控制、图谱节点与边查看/导出、聚类管理、配置与状态监控。
- 范围外：LLM 权重微调、源笔记文件的直接编辑、Sirchmunk Chat 页面的移植、文件上传与集合管理。

## 第二部分 业务功能与规则
### 2.1 业务功能 (FUNC)
- **FUNC-01~06**：服务连接的创建、修改、检查、停用/移除，及 MCP 绑定的创建与验证。
- **FUNC-07~09**：发起检索委托、消费/展示结果、有限重试。
- **FUNC-10~15**：打开管理中心、查看图谱、查看/管理知识聚类、查看历史、查看监控、查看/修改UI设置。
- **FUNC-16**：导出当前图谱视图。
- **FUNC-17**：导出全部可见图谱。

### 2.2 业务规则 (R)
- **R-01**：服务地址安全规则。
- **R-02**：敏感配置隔离与脱敏规则。
- **R-03**：MCP 能力兼容规则（需包含 sirchmunk_search）。
- **R-04**：移除连接不级联删除历史与知识数据。
- **R-05**：检索成本控制（Agent 按复杂度选择模式，不拆分内部步骤）。
- **R-06**：检索失败不自动降级使用 DSH 昂贵模型。
- **R-07**：管理页面能力透传（只读、无 iframe、无假功能）。
- **R-08**：写操作需二次确认，以后端成功为准，不补偿。

## 第三部分 业务对象 (OBJ)
### 3.1 DSH 插件管理对象
- **OBJ-01 服务连接**：DSH 访问的 Sirchmunk 实例。
- **OBJ-02 MCP 绑定**：服务连接与 DSH MCP 之间的关联。
- **OBJ-03 管理页面入口**：插件提供的非 Chat 页面配置。

### 3.2 运行时对象 (复用 DSH 轨迹)
- **OBJ-04 检索委托**：单次 MCP 调用。
- **OBJ-05 检索结果**：Sirchmunk 的答复与来源。
- **OBJ-06 证据来源引用**：高保真定位。

### 3.3 外部权威对象 (只读或受控写)
- **OBJ-07 外部知识聚类**：知识概念节点。
- **OBJ-08 外部图谱关系**：节点间拓扑。

## 第四部分 流程 (PROC)
- **PROC-01 检索委托流**：提问 -> MCP 调用 -> 本地检索 -> 返回答案与证据 -> 结束。
- **PROC-02 管理与图谱访问流**：进入入口 -> 鉴权 -> 读取数据 -> (可选二次确认写) -> 刷新 -> 结束。
- 无人工审批流。

## 第五部分 跨对象联动 (LINK)
- **LINK-01**：修改连接 -> 刷新健康状态。
- **LINK-02**：检查连接 -> 刷新能力可用性。
- **LINK-03**：绑定 MCP -> 验证工具能力。
- **LINK-04**：停用/移除连接 -> 阻止新访问。
- **LINK-05**：检索成功 -> 生成结果。
- **LINK-06**：写操作成功 -> 刷新页面。
- **LINK-07**：修改设置 -> 必要时重新检查。

## 第六部分 查询统计与报表 (REP / Q)
- **REP-01 (Q-01)**：服务连接状态查询。
- **REP-02 (Q-02)**：MCP 绑定状态查询。
- **REP-03 (Q-03)**：知识图谱拓扑查询。
- **REP-04 (Q-04)**：知识聚类查询。
- **REP-05 (Q-05)**：Sirchmunk 历史查询。
- **REP-06 (Q-06)**：运行监控查询。
- **REP-07 (Q-07)**：脱敏设置查询。

## 第七部分 岗位角色与功能权限 (ROLE)
- **ROLE-01 使用者**：日常检索、查看图谱/聚类/历史/基础状态、导出当前视图。
- **ROLE-02 管理员**：维护连接与绑定、受控删除聚类、查看完整监控、修改UI设置、导出全部图谱。
- **ROLE-03 DSH Agent**：按当前用户权限代发起检索委托。
- **ROLE-04 Sirchmunk Agent**：外部系统执行者。
- **ROLE-05 插件运行时**：API 安全转发与渲染。

## 第八部分 MU UI 模型与原型
- **UI-01 设置入口**：单表概览，显示 HTTP/MCP 状态及管理中心入口。
- **UI-02 服务连接管理**：列表 + 新增/编辑/检查。
- **UI-03 MCP 绑定管理**：列表 + 验证工具。
- **UI-04 知识图谱**：查询列表特化（画布+右侧面板），支持筛选和导出。
- **UI-05 知识聚类**：查询列表 + 详情。
- **UI-06 Sirchmunk 历史**：共享历史列表。
- **UI-07 运行监控**：分类状态仪表盘。
- **UI-08 Sirchmunk 设置**：只读/可受控修改的配置列表。
